# it-lecture-2026
## О лекции

В рамках лекции рассмотрены виды профессиональной информационной деятельности 
и три направления развития ИТ-специалиста: **наука**, **инженерия** и **разработка**.

## Рассмотренные платформы

### GitHub Education (Student Pack)
- Пакет доступа к профессиональным инструментам и сервисам
- Включает: GitHub Pro, GitHub Copilot, облачные кредиты, домены
- **Статус:** официально недоступен для пользователей из РФ

### GitVerse Образование (Education Pack)
- Образовательная экосистема с готовыми курсами и заданиями
- Включает: Bootcamp Labs, GitVerse Lab, GigaIDE Cloud, GigaCode
- **Статус:** полностью доступен для студентов, преподавателей и вузов РФ
